🍴 About FOKIRA CAFE
FOKIRA CAFE is a simple and responsive cafeteria website created to make browsing food items and placing orders easy. The project uses HTML, Tailwind CSS, and JavaScript to provide a clean interface and interactive ordering experience.
✨ Features
Feature	Description
🍔 Menu	Browse the available food items
🛒 Cart	Add items and review your selection
🧾 Order System	Place an order through the website
📱 Responsive Layout	Works across different screen sizes
🎨 User-Friendly UI	Clean and easy-to-use interface


🧰 Tech Stack
- HTML5 — Website structure
- Tailwind CSS — Styling and responsive design
- JavaScript — Interactive functionality

💻 Getting Started
Run this project locally in a few steps.
1. Clone the repository
git clone https://github.com/bicromroy/fokira-cafe.git
2. Open the project folder
cd fokira-cafe
3. Launch the website
Open index.html in your browser. You can also use the Live Server extension in VS Code.
