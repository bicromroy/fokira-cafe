📖 About The Project

FOKIRA CAFE is a cafeteria website built with HTML, Tailwind CSS, and JavaScript. It provides a simple interface for exploring food items, managing a cart, and placing orders.

✨ Features

🍔 Food Menu — Browse available food items.

🛒 Shopping Cart — Add items and review your selection.

🧾 Order System — Place orders through the website interface.

🧮 Bill Invoice — View a colorful order bill.

📱 Responsive Design — Designed for different screen sizes.

🎨 Clean UI — Simple and user-friendly interface.
